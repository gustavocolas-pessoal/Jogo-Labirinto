# Jogo-Labirinto
Projeto que visa oferecer uma maneira lúdica de aprender algoritmos computacionais por meio de um jogo de labirinto. Esse trabalho foi realizado para o Ilum Portas Abertas (IPA), durante o segundo semestre de graduação dos alunos Arthur Cunha, Camila Cunha e Gustavo Junqueira Colas
